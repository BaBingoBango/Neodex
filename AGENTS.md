### MCPs
You have access to the following MCP tools:
- GitHub
- Xcode
- Firebase

However, do NOT directly read `.mcp.json` as it contains a GitHub key.

Also, with the Xcode MCP you may encounter a "delay" or permission issues with approval, as your approval sends a GUI prompt (Xcode also usually has to be open) that may not be approved right away. If you run into tool issues or need to request Xcode MCP permission, it is best to stop work and wait for the user (hi!) to complete the prompt, then continue on the next turn.

### Misc.
For testing on Apple platforms, confirm on a small device in addition to any testing you do otherwise - for instance, the app should look great on the iPhone 17e (iOS 27) as that is the smallest current display.
